# Marketplace Analytics Dashboard

Модуль импорта и анализа данных с маркетплейсов Wildberries и Ozon.

## Возможности
- Загрузка Excel-отчётов WB и Ozon
- Автоопределение типа отчёта
- Парсинг и нормализация данных в SQLite
- Расчёт метрик: выручка, прибыль, возвраты, топ товаров
- Интерактивный дэшборд

## Стек
Python, pandas, SQLite, Streamlit, Plotly

## Запуск
pip install -r requirements.txt
streamlit run app.py
